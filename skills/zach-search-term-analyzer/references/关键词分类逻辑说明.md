# 亚马逊搜索词场景分类逻辑说明

**版本**: v3.0（场景化框架，取代 v2 的 8 分类）
**更新日期**: 2026-08-20

---

## 为什么从 8 分类换成场景框架

v2 的 8 分类（黄金/潜力/红海/避坑 × 大词/长尾）存在三个无法自圆其说的问题：

1. **"转化效率比"语义错位**：TOP3 转化份额之和 ÷ 点击份额之和衡量的是**头部竞品的转化集中度**（头部满足度），不是"这个词转化好坏"，更不是你的 Listing 好坏——你的 Listing 不在数据里时，优化自家页面不可能改变该指标
2. **同一比值的褒贬取决于视角**：你不在 TOP3 时，比值 <1（转化外流）反而是**机会信号**；v2 却把它判成"低转化→潜力/避坑"
3. **缺失当零**：ABA 中"点击 TOP3 转化份额为 0/缺失"是高频真实现象（转化分散到长尾或被脱敏），v2 把缺失 fillna(0) 后判成"避坑"，违反数据诚信红线

v3 的解法：**先判断自家 ASIN 在不在该词点击 TOP3，再选用对应的判断框架。**

---

## 指标口径（判定的地基）

| 指标 | 公式 | 语义 |
|---|---|---|
| 成交系数（per-ASIN，业内标准） | 该 ASIN 转化份额 ÷ 点击份额 | = 该 ASIN 转化率 ÷ 该词平均转化率。≥1 = Closer（接得住流量）；<1 = 流量磁铁（拿点击不拿单） |
| 点击集中度 | SUM(TOP3 点击份额) | 该词点击蛋糕被头部吃掉多少；剩余散布在长尾 ASIN（合计远小于 100% 是常态） |
| 转化集中度 | SUM(TOP3 转化份额) | 该词购买被头部吃掉多少 |
| 头部满足度 | 转化集中度 ÷ 点击集中度 | ≥1 = 头部接得住需求；<1 = 转化外流到 TOP3 之外（需求未被头部满足） |

⚠️ 点击份额与转化份额是**独立指标**（亚马逊官方口径）：买家可以点 A 买 B，单 ASIN 转化份额可以大于点击份额。

---

## 场景路由

```
自家 ASIN ∈ 该词点击 TOP3 ？
├─ 是 → 场景 A：存量经营（自家行分析）
├─ 否 → 场景 B：市场进入（市场结构分析）
└─ 未提供自家 ASIN → 全部场景 B + 显著标注"仅市场视角"
```

为什么以此为分水岭：ABA 只披露点击 TOP3 的行级数据。你在 TOP3 → 拿得到**自家精确份额**，做的是运营诊断；你不在 → 只能看市场结构，做的是进入决策。两者的数据可用性和业务问题完全不同。

---

## 场景 A：自家在 TOP3（存量经营）

判定基于**最新一期**自家行（多自家 ASIN 同词上榜时份额求和）：

```
自家 ASIN 曾在该词 TOP3
├─ 最新一期已掉出 TOP3 ················· A4 份额预警
├─ 点击份额 − 转化份额 > 4pt ··········· A2 漏水词
├─ 自家成交系数 ≥ 1.0 ·················· A1 收割词
└─ 其余 ································ A5 平衡词
附加 flag：
├─ 自家点击份额连续 ≥3 期下滑 ·········· 份额下滑预警
└─ 同词 TOP3 竞品成交系数 < 1 ··········· 截流机会（列出目标 ASIN）
```

| 状态 | 动作 |
|---|---|
| A1 收割词 | 防守+放量：加预算、防御性投放、盯竞品进入 |
| A2 漏水词 | **先修详情页再抬价**：价格/评价/主图/A+ 逐项排查；用 SQP 定位漏斗卡点（曝光→点击→加购→购买哪层漏） |
| A4 份额预警 | 排查排名/价格/断货/新竞品；触发 competitor-deep-dive |
| A5 平衡词 | 维持现状，周度跟踪 |

---

## 场景 B：自家不在 TOP3（市场进入）

先做数据状态门：转化数据缺失 / 全 0（分散或脱敏）→ **B0 数据不足**，不进象限，转 SQP/广告数据验证。

数据正常时进四象限：

```
                     头部满足度 < 1.0            头部满足度 ≥ 1.0
                     （转化外流）                （头部接得住）
点击集中度 < 50%   B1 机会词 ⭐优先级最高      B2 常规竞争词
（分散）           头部接不住需求，转化流向     蛋糕未整合、头部转化健康
                   TOP3 之外——能接住就进       常规差异化+正常出价测试

点击集中度 ≥ 50%   B4 伏击词                   B3 头部满足词
（集中）           头部霸点击但买家买别家       头部垄断且高效满足市场
                   竞品定向+压价偷单，          避其锋芒，找相邻长尾
                   不打点击战                   切入，不正面竞价
```

附加信号（叠加在象限之上）：

| 信号 | 判定 | 含义 |
|---|---|---|
| 垄断红线 | 点击或转化集中度 ≥ 70% | 头部深度垄断，进入需极强差异化 |
| 蓝海信号 | SFR ≥ 20万 且 TOP3 份额 ≥ 60% | 未开发利基：词很深但被少数玩家吃满，单词 2-3 单也可观 |

**B1 投放前置检查**：转化外流 ≠ 你一定接得住。投放前核对 TOP3 ASIN 与自家产品的属性一致性（产品类型/人群/场景/价格带/档次，5 维中 ≥3 一致才视为同赛道）。

---

## SFR 五级分层（预算量级标签）

不参与象限判定，决定词的用途与预算量级：

| 层级 | SFR 区间 | 用途 |
|---|---|---|
| T1 核心大词 | ≤ 1万 | 排名用（关联流量入口） |
| T2 次核心大词 | 1万 - 2万 | 排名+转化兼顾 |
| T3 中量词 | 2万 - 5万 | 中等流量补充 |
| T4 中长尾 | 5万 - 10万 | ROI 导向 |
| T5 长尾 | > 10万 | 追 ACOS |

## 阈值依据与校准

**所有阈值都是多源实战经验默认值，不是亚马逊官方标准**，脚本参数可按类目覆盖：

| 阈值 | 默认值 | 依据 | 参数 |
|---|---|---|---|
| 点击集中度：未整合上限 | 30% | 英文卖家社区共识"<~30% = unconsolidated keyword, attack first" | `--click-conc-scattered` |
| 点击集中度：集中下限 | 50% | 多源"50-70% 高度集中慎入"取下界 | `--click-conc-concentrated` |
| 垄断红线 | 70% | 中文社区（知无不言）"前三转化份额相加超 70% = 垄断竞争激烈" + 英文社区 click 集中 70% 案例 | `--monopoly-redline` |
| 成交系数 / 头部满足度分界 | 1.0 | 公式自然分界（= 词均转化率） | `--coefficient-threshold` |
| 自家漏水判定差值 | 4pt | 运营圈经验"Click Share − Purchase Share 超 4 个点 = 点击拿到没转化，优先修 Listing" | `--own-gap-points` |
| SFR 分层边界 | 1万/2万/5万/10万 | 中文社区五级分层实战法 | `--sfr-tiers` |
| 蓝海信号 | SFR≥20万 且份额≥60% | 中文社区"排名 20万+ 但点击/转化份额极高 = 未开发市场" | `--bluesea-sfr` / `--bluesea-share` |

校准原则：在自己类目跑 4+ 期数据，观察各象限词的实际广告表现（CVR/ACOS），回头调阈值；跨类目分析时优先调 `--sfr-tiers`（类目体量差异最大）。

---

## 复盘节奏

建议每周（周报粒度）复盘：
1. 场景 A：A2 漏水词修复后系数是否回升；A4 预警词的竞品动作
2. 场景 B：B1 机会词投放后的实际 CVR 是否验证"外流可接"；不达预期回查属性一致性
3. 象限迁移：B1 → 自家进 TOP3（场景 B→A）是进入成功的标志
4. 阈值校准：每季度用实际广告数据回归一次默认阈值

---

**说明**：本分类逻辑基于亚马逊 Brand Analytics 热门搜索词报告，帮助运营快速判断"这个词跟我什么关系、该做什么动作"。ABA 代表热度流量、不必然代表市场需求全貌；结论需结合 SQP、PPC 数据与前台验证。
