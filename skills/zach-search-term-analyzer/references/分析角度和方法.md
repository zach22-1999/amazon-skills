# 亚马逊搜索词报告 - 分析角度和方法

**版本**: v3.0（2026-08-20，与场景化框架同步）

## 分析框架总览

```
Brand Analytics 热门搜索词报告
        │
        ├─ 0. 场景路由（自家 ASIN 在/不在点击 TOP3）← v3 新增，决定后续所有判断视角
        ├─ 1. 品牌竞争分析      → 词群守门人识别
        ├─ 2. 类别趋势分析      → 类目节点与跨类目机会
        ├─ 3. 搜索词场景分析 ⭐⭐ → 场景 A 状态 / 场景 B 象限 + SFR 分层
        ├─ 4. 词频统计分析 ⭐    → 标题/五点/后台关键词素材
        ├─ 5. 竞争格局分析      → 点击 TOP3 商品层攻防
        ├─ 6. 成交系数分析 ⭐    → 自家自诊 + 截流目标 + 逆向学习
        └─ 7. 时间序列分析      → 核心词趋势与份额变化
```

判定标准与阈值出处统一见《关键词分类逻辑说明.md》，字段口径见《字段说明.md》，本文只讲每个维度**怎么用**。

---

## 0. 场景路由（一切分析的前置）

**为什么**：ABA 只披露点击 TOP3 的行级数据。自家在 TOP3 → 拿得到自家精确份额，做运营诊断；不在 → 只能看市场结构，做进入决策。混用视角是 v2 时代最大的方法论错误。

**怎么做**：运行脚本时传 `--own-asins`。上架后周期性分析必传；上架前市场调研可不传（全部场景 B）。

---

## 1. 品牌竞争分析

**目标**：识别词群的流量守门人与品牌格局。

**指标**：品牌在各搜索词点击 TOP3 位置的上榜次数、位次分布、上榜次数占比。

**⚠️ 口径**：上榜次数占比反映品牌对热搜词的**覆盖广度**，不是市场销售份额。

**实操应用**：
- 头部品牌（TOP3）：避免正面竞价其品牌词；研究其占位词群作差异化参照
- 腰部品牌（6-15 名）：学习其在头部夹缝中的生存打法（价格带/差异化卖点）
- 自家品牌上榜：品牌词防御性投放
- 领星源无品牌字段：此维度空置，用 05 竞争格局的 ASIN 层替代

---

## 2. 类别趋势分析

**目标**：确认类目节点选择、发现跨类目机会。

**实操应用**：
- 主分类对齐主导类别；不一致时评估类目节点迁移
- 次要类别（4-8 名）提示跨场景需求：Listing 文案与 A+ 覆盖对应场景
- 类别分布突变（时间序列观察）提示品类边界移动

---

## 3. 搜索词场景分析 ⭐⭐（核心维度）

**目标**：回答"这个词跟我什么关系、该做什么动作"。

**指标**：SFR（均值/最新/最佳/最差/标准差）、SFR 五级分层、点击集中度、转化集中度、头部满足度、数据状态、场景状态、垄断红线、蓝海信号、自家份额与成交系数、截流目标 ASIN。

**方法**：见《关键词分类逻辑说明.md》的场景路由 + 场景 A 状态机 + 场景 B 四象限。

**实操应用**：

| 你想做的事 | 看什么 |
|---|---|
| 新品选词 | 场景 B：B1 优先（先做属性一致性检查）、B2 次之；避 B3 与垄断红线 |
| 老品放量 | 场景 A：A1 加预算；A2 先修详情页（这是花钱前的止损点） |
| 打竞品 | 「截流目标ASIN」列 + 06 报告的流量磁铁清单 |
| 找利基 | 蓝海信号词（SFR 深但份额被少数玩家吃满） |
| 防守 | A4 预警词立即排查；A1 词盯竞品进入 |

**⚠️ 不要做的事**：
- 不要把 B1"转化外流"直接当"我能接住"——先核对 TOP3 属性一致性（5 维中 ≥3 一致）
- 不要用本报告生成否定词——否词由自家 PPC 搜索词报告决策
- 不要拿单期低频词下结论——结论以多期复现为准

---

## 4. 词频统计分析 ⭐

**目标**：把搜索词拆成可复用的关键词素材（人群/场景/属性/品牌/核心词 + 双词短语）。

**口径**：按**去重搜索词**计数（一个词多期出现只计一次）；双词短语只取原始搜索词中**真实相邻**的内容词组合。

**实操应用**：
- **标题结构**：品牌词 + 核心词 + 高频属性词 + 人群词 + 场景词；高频词原词呈现提升搜索结果页相关性感知
- **五点/A+**：每个 bullet 围绕一个场景词/人群词（可配合 AI 意图注解）
- **后台 Search Terms**：补前台没放下的长尾词根，不重复前台已用词
- **广告选词**：高频双词短语直接作精准/词组匹配候选
- 词面标签只是初筛，可让 AI 助手对高频词补充买家意图注解作语义层

---

## 5. 竞争格局分析（点击 TOP3 商品层）

**目标**：识别高频上榜商品，建立攻防对象清单。

**⚠️ 对象口径**：表中 ASIN 是"点击王"（含广告位点击），不是"转化王"；真正的 closer 可能不在表里。多为竞品，自家已标 ★。

**实操应用**：
- 高频上榜竞品 = 差异化基准：拆其标题结构/主图/价格带/A+/评论关注点
- 上榜次数多但成交系数低的竞品 → 优先截流对象（转 06 报告）
- 自家 ASIN 上榜情况 = 场景 A 的入口清单

---

## 6. 成交系数分析 ⭐（per-ASIN，业内标准公式）

**目标**：用 `转化份额 ÷ 点击份额` 判断每个 ASIN 在词下的真实转化力。

**公式含义**：成交系数 = 该 ASIN 转化率 ÷ 该词平均转化率（推导：两个份额同除以该词总点击/总购买，词级总量约掉）。

**实操应用**：

| 对象 | 系数 ≥1（Closer） | 系数 <1（流量磁铁） |
|---|---|---|
| 自家 | 转化力是优势 → 放量防守 | 先修详情页再抬价；差 >4pt 优先级最高；用 SQP 定位漏斗卡点 |
| 竞品 | 逆向学习：拆它为什么接得住单；正面竞价需谨慎 | **截流目标**：SP/SD 商品定向 + 有竞争力的价格/评价承接其外流转化 |

**⚠️ 边界**：数据不足（转化缺失/脱敏）不判定；系数基于跨期平均，单期波动大。

---

## 7. 时间序列分析

**目标**：追踪核心词（每期都出现的词）的排名趋势与自家份额变化。

**指标**：分期搜索词数量（⚠️ 反映报表导出范围而非市场大小）、核心词中位排名、核心词 TOP10 首期→末期排名变化、趋势图。

**实操应用**：
- 核心词排名持续上升（数字变小）→ 需求升温，广告与库存提前联动
- 排名持续下降 → **跨年同期**对比确认是季节回落还是需求转移；单一时间窗内不下旺季/淡季结论
- 新上榜高位词 → 新场景/新竞品带起的需求，及时补词库
- 场景 A 用户加看：自家点击份额周环比（03 的 A4/下滑 flag）

**季节性产品特别提示**：强季节品以**上个旺季同期**报告为主做选词，近期报告只作补充；不同时段报告分开分析，不要合并求均值。

---

## 分析节奏建议

| 阶段 | 频率 | 重点维度 |
|---|---|---|
| 上架前调研 | 一次性（多期数据） | 3（场景 B）、4、1、2 |
| 上架后运营 | 每周（周报节奏） | 3（场景 A 状态迁移）、6、7 |
| 季度复盘 | 每季度 | 7（跨期趋势）+ 阈值校准（用实际广告数据回归） |

**验证闭环**：本报告的所有判断都是**先验**——B1 的"外流可接"、A2 的"漏水原因"，最终以 SQP（自家漏斗份额）与 PPC 数据（实际 CVR/ACOS）验证。
